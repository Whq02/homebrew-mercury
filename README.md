# homebrew-mercury

The Homebrew tap for [Mercury](https://mercury-cli.ai), a terminal harness for software development.

```sh
brew install Whq02/mercury/mercury
mercury
```

The formula installs the release archive for your machine from
[github.com/Whq02/MercuryCLI/releases](https://github.com/Whq02/MercuryCLI/releases)
(Apple silicon Macs and Linux x64; Windows uses the PowerShell installer at
https://mercury-cli.ai). Each archive carries its own Node runtime and ripgrep.

Source, issues and the licence: https://github.com/Whq02/MercuryCLI
